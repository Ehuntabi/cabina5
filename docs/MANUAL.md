# Este manual se ha unificado

Había dos manuales y el de verdad es **uno solo**:

    ~/joint/manual/manual_uso_autocaravana.md

(`~/joint/manual` es un enlace a `~/joint/documentacion/manual`: la misma
carpeta con dos nombres.)

De ahí se generan el **PDF** y el **HTML** que se leen de verdad
(`manual_uso_autocaravana.pdf`, `manual_uso_autocaravana.html`), con sus
imágenes en `documentacion/manual/imagenes/cabina/` y el vídeo en
`documentacion/manual/video/`.

Este fichero era un manual paralelo y se retiró el 10-nov-2026 para que no
vuelvan a divergir dos textos que cuentan lo mismo (pasó justo con la pantalla
de inclinación: se actualizó este y no el que se lee). El contenido anterior
sigue en el historial de git (`git log -- docs/MANUAL.md`).

Para lo técnico del firmware no hay manual aparte: está en `CLAUDE.md` (este
repo), en `README.md` y en `docs/`.
